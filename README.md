# 曲QR

楽譜を1枚のQRコードに入れて、読み取るとその場で鳴らせるページです。ネットにつながっていなくても動きます。

公開ページ: https://yannsi.github.io/kyoku-qr/

## しくみ

- QRに入れるのは音そのものではなく、MML という文字で書いた楽譜です
- 楽譜をブラウザの圧縮機能（deflate）で小さくして、QRに詰めます
- 読み取ると、ページが楽譜を読んで Web Audio で音を作ります

## つかいかた

1. 「つくる」で楽譜を書く（見本の曲から始められます）
2. 下に出るQRを保存・印刷する
3. 「よみとる」でカメラを向けるか写真を選ぶと、曲が開きます

「QRの中身」を「URLつき」にすると、スマホの普通のカメラで読んでもこのページが開きます。

## 使っているもの

- QR作成: qrcode-generator（MIT）
- QR読み取り: jsQR（Apache-2.0）

どちらも index.html の中に入れてあるので、このファイル1つで動きます。
